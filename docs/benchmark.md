# Benchmark method and next case

The current 13-slide example demonstrates shell features. It is not a new source-to-HTML conversion benchmark. A separate source-to-result case is planned after the publisher supplies material and its sharing scope is established.

For that case record: exact source/version/hash, task and style reference, model and effort, machine/browser, package versions, content completeness, visual issues, manual corrections, final artifacts and remaining limits. Separate LLM stage time from deterministic converter wall time. Record actual tokens/cost only when available; never infer them from a subscription multiplier or script speed.

For optimization compare the same input and acceptance bar, repeat cold/warm/one-slide-edit runs, and report dispersion and which caches were reused. Native PowerPoint and Windows evidence stay separate. A resource win is valid only after the same quality criteria pass.

Export references retain historical internal-corpus observations, including a precisely scoped historical Anthropic helper comparison. The private input decks/proofs are not bundled, and the figures are not a reproducible public benchmark or a comparison of entire LLM products.
