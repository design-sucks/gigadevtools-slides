# GigaDevTools Slides — corporate pilot v0.5.1-pilot.1

Two portable Agent Skills: **HTML Maker 0.21.1** (PPTX/content → editable offline HTML) and **HTML Export 0.9.1** (HTML → viewing PDF/editable PPTX). The accepted shell remainsv18.2; the demonstration deck staysv01.

## In this update

-24 accepted, anonymized composition references: covers, prose, tables, diagrams, charts, feature cards and pipelines. Input/reference colors and graphics take precedence over example paint. The simplified 18-pattern renderer remains for compatible pinned projects.
- Source-style inventory and decisions, retained graphic instances, explicit export theme/format and font-aware editable export.
- Shared navigation/background motion fixes and translucent neutral shell surfaces accumulated since the earlier public pilot.
- Clear review instructions and honest limitations for paragraph density, long lines and awkward wraps. This release does **not** claim that typography or design quality is automatically solved.

## Verification and limits

All 24 reference screenshots match the accepted review after font deduplication. A fresh private 10-slide PPTX case was rebuilt and exported to HTML/PDF/PPTX; source content/graphics and all-page PowerPoint Mac rendering were checked. The user still judged its design too primitive and identified text-layout weaknesses. Treat this as working pipeline evidence, not design approval or a universal conversion benchmark. Native Windows rendering and manual edit-save were not checked in that run.

Private source decks, raw captures, local paths/configuration and caches are excluded. Our original code/docs are MIT; SB Sans binaries and embedded font copies retain separate third-party terms and are excluded from MIT. This is a corporate pilot, not a general font-license grant.
