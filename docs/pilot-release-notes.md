# Corporate pilot · v0.7.1-pilot.1

HTML Maker **0.22.0-rc19.1**; HTML Export **0.9.1** без изменений.

## Что исправлено

- На узких экранах восстановлены поля 8+8 px вместо ошибочных 20+8 px: масштаб и положение содержимого снова соответствуют исходному эталону. Фон остаётся на всё окно.
- Compact-тест сохраняет геометрию и сведения о шрифтах перед падением. Эталон и допуск 0,7 px не изменены.
- Устаревшая проверка темы навигации заменена точной проверкой согласованной дедупликации: заголовок и исходная тема сохранены, повтор в навигации убран.
- Новый пакет включает эти исправления, ранее доступные только в main и демо. Все возможности RC19 сохранены; новых библиотек нет.

## Проверки

Включённый runtime прошёл полный Linux CI: 13 слайдов, 2 темы, 4 размера окна, 104 сравнения якорей, 208 состояний покоя, показ/экспорт, миниатюры, edit/undo и N/M. Намеренный сдвиг заголовка тест обнаруживает. [Проверка main](https://github.com/design-sucks/gigadevtools-slides/actions/runs/42516574061), [подробный разбор](HTML_Maker_Linux_Compact_Fix_v01.md). Новый номер версии меняет упаковку и документацию; runtime идентичен проверенному исправлению.

Большие новые прогоны реальных презентаций, Windows и native PowerPoint не добавлялись. Пакеты: `gigadev-html-maker.zip`, `gigadev-html-export.zip`, `gigadevtools-slides.zip`, `manifest.json`, `SHA256SUMS`. Предыдущий релиз v0.7.0-pilot.1 не перезаписывается. Корпоративный prerelease; условия SB Sans не меняются.
