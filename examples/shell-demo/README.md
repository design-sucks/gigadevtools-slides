# Shell demo v01

Open index.html online or locally. Fonts and vector graphics are embedded. The 13 slides explain the UI: viewing/clicker, hotkeys, text editing, organization, journal, themes/calibration, saving and the Maker/Export boundary. Saving creates v02.

The authoring source is project/deck.json plus project/theme.json and supplied fonts. Run python3 scripts/build_demo.py from the repository root to rebuild both this file and the exact docs/index.html Pages copy. Do not independently edit generated copies.

This is the accepted corporate SB Sans profile. [Font terms](../../THIRD_PARTY_NOTICES.md) are separate from MIT. The tutorial is not an example of a newly measured arbitrary-PPTX import; a real source-to-result case will be added after testing separate material.
