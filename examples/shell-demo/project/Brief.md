# Принятая демо-презентация v01

Содержание и оболочка принятой рабочей v05 сохранены: 13 слайдов, две темы, SB Sans Text/Display/Extended, хоткеи, журнал, сохранения, компактный свободный просмотр без хвостов соседних слайдов.
