# RC14: bounded text preparation and translucent shell

Ordinary builds apply conservative Russian typography; review/off remain explicit. Existing applied typo corrections are merged only on matching after-text. Basic inline emphasis tags retain markup while their separate text nodes normalize. Cross-run quotes, links, code, arbitrary spelling and semantic punctuation require agent proofreading before build and exact journal records. Logical paragraphs stay editable; line width and browser pretty/balance are authored and measured, not universal automatic redesign.

Title and navigation surfaces pair opaque ink with translucent backgrounds; title child color inherits correctly. Qualified on one 5-slide native PPTX derivative from GLM, two themes and explicit/auto ink modes. No broad regression or PowerPoint export qualification is claimed.

RC15 corrects the RC14 navigation regression: inactive rows are transparent, hover is temporary, only one animated active bubble paints. Single-theme builds hide the switch in generated markup before scripts execute; a programmatic click cannot enable an undeclared theme.
