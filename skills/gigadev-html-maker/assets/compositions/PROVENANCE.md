All HTML is rebuilt on clean markup. Source corporate copy, names, facts, people, domains, logos, screenshots, videos, original IDs, comments and hidden deck state are excluded from examples/templates/media/previews. Synthetic values are explicitly labelled educational examples. Geometric SVG placeholders say to replace them with project material. Generic reference labels A/B preserve traceability without embedding private source paths or content. SB Sans follows the existing corporate-pilot distribution notice and is not licensed by the code's MIT license.

Composition and typography are adapted for the common 1920×1080 canvas and 1696×874 safe frame; these are not exact screenshot clones. Color/font/media inheritance is performed per new project. The source style and any mandatory supplied layout take precedence.
