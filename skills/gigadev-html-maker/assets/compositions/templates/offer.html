ПРИМЕР КОМПОЗИЦИИ

Два формата для разных условий

ВАРИАНТ A

Базовый формат

Один сценарий

Подходит для первого запуска и проверки подхода.

  • Небольшой объём материалов
  • Понятные условия старта
  • Проверка на одной задаче

ВАРИАНТ B

Расширенный формат

Набор сценариев

Подходит для регулярного использования командой.

  • Больше типов материалов
  • Общие правила работы
  • Повторяемая проверка результата

Общие условия и ограничения указываются отдельно, чтобы не повторять их в каждой колонке.

Учебный пример. Все названия, показатели и изображения заменяются данными проекта.
