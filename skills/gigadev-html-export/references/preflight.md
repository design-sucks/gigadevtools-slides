# Profiles and compatibility

The registry is profiles/registry.json. A profile matches only when runtime, canvas dimensions, ordered top-level slide IDs and per-slide structural SHA-256 signatures match. Signatures include element tags and CSS classes except transient active/is-active; text and asset bytes are not part of family recognition. Recomputed scene geometry and strict export verification still apply. A filename change is harmless; structural edits deliberately require review. A match does not certify that new content fits.

Four known families: AI PDLC Status (11 slides), GigaDev Editable (18), GIGA Brand (15 main), Meetup (14). Only the first two have tested grouping rules. `--groups auto` loads the matching group's JSON and validates expected selector counts on every referenced slide before packing fonts. No match, ambiguity, missing grouping rules or wrong counts blocks auto grouping. `--groups /absolute/profile.json` is an explicit inspected override; its selector counts still must match. Default export recognises the family but does not group unless requested.

Blockers include invalid canvas, failed image/font loading, non-data font faces that need a packing adapter, missing native-counter candidates, unsupported/missing SVG path markers and invalid group selectors. PDF-only does not inherit PPTX counter/marker/font-pack requirements. Review notices include unknown structure, assumed canvas, complex paint, static video/canvas fallback, network assets and absence of embedded fonts. Inspect mode writes issues without starting reconstruction. This is a set of known hazard checks, not an exhaustive CSS/SVG support guarantee. Lazy images, CSS backgrounds and source resources with unusual custom loaders still require native proof review.

Do not add fingerprints from a source merely because inspection succeeded. Register a family after its actual export/native proof is accepted, record the tested grouping file when one exists, and rerun renamed/mutated-source regressions. Duplicated matches are configuration errors. No automatic registry write happens during export.
